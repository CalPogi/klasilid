Questions advisers ask

What happens when the internet is down?

The reader keeps working. It saves each tap with the right time and sends them once the internet is back.

Can a learner tap for a classmate?

A card can be lent, so the seat plan shows who should be in each seat. One look tells you if a seat is empty, and any day can be corrected with a reason.

How do I get an account?

Open the sign-up link from the Klasilid admin. You receive it when your door reader is set up.

Windows says it protected my PC

Click More info, then Run anyway. Klasilid isn’t in the Microsoft Store yet.

Android won’t install it

Open Klasilid.apk from your downloads. If asked, allow Install unknown apps for your browser, then tap Install. Klasilid isn’t on Google Play yet.
