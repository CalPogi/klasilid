Turn on two-step sign-in

The admin section needs a code from your phone as well as your password. You set this up once.

  1. 1Install an authenticator app, like Google Authenticator.
  2. 2In the app, add an account and scan this code.
  3. 3Type the 6-digit code the app shows.
